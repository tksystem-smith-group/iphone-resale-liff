利用規約

合同会社TKSystem（以下「甲」）は、LINE公式アカウント「iPhone転売ツール」を通じて甲が提供するサービス（以下「本サービス」）の利用について、以下のとおり利用規約（以下「本規約」）を定めます。本サービスの利用を希望する者（以下「乙」）は、本規約の内容に同意した上で、本サービスを利用するものとします。

第1条（本規約の目的及び適用）

  1. 本規約は、甲が本サービスを通じて乙との間で行う商品の買取契約及びこれに付随する事項について、甲乙間の権利義務関係を定めることを目的とします。
  2. 乙は、本サービスの利用申請をもって本規約に同意したものとみなします。本フォームにおいて同意確認を求める場合、当該同意操作をもって効力を生じるものとします。

第2条（定義）

本サービス：甲がLINE公式アカウント「iPhone転売ツール」を通じて提供する、乙が購入した新品iPhoneを甲が買い取るサービス及び付随する案内・通知機能。対象商品：Apple Storeにて乙が新規に購入する新品未開封のiPhone。買取契約：第7条に基づき対象商品について甲乙間に個別に成立する売買契約（甲を買主、乙を売主とする）。買取代金：買取契約に基づき甲が乙に支払う対価。サロン：乙が会員として所属する、甲が提携する会員組織。

第3条（本サービスの内容）

  1. 本サービスは、乙が対象商品をApple Storeにて購入し、甲があらかじめ指定する保管先（以下「指定倉庫」）へ発送した後、甲が対象商品を乙から買い取り、その代金を乙の指定する銀行口座へ振り込むことを内容とします。
  2. 本サービスにおいて甲が乙から金銭を預かり、又は乙に代わって送金・決済を行う事実はありません。本サービスは、乙が甲に対象商品を売却し、甲がその対価を支払うという売買契約の実行に尽きるものであり、資金決済に関する法律上の資金移動業その他の資金移動サービスには該当しません。

第4条（利用登録）

  1. 本サービスの利用を希望する者は、LINE公式アカウントを友だち追加の上、所定の方法により利用を申請するものとします。
  2. 甲は、申請者がサロンの会員であることその他甲が定める基準に基づき審査を行い、利用の可否を決定します。甲は、利用登録の可否について理由を開示する義務を負いません。
  3. 利用登録が承認された乙は、甲が指定するフォームにより、氏名、住所、振込先口座情報、本人確認書類その他甲が必要とする情報（以下「登録情報」）を提出するものとします。
  4. 乙は、登録情報に変更が生じた場合、速やかに甲の定める方法により変更の届出を行うものとします。

第5条（利用資格及び反社会的勢力の排除）

  1. 本サービスは、20歳以上の個人であって、暴力団等の反社会的勢力に該当しない者、過去に甲との取引において重大な契約違反がない者、提出情報に虚偽がない者に限り利用できるものとします。
  2. 乙は、自らが前号に該当しないこと及び将来にわたっても該当しないことを表明し、保証します。

第6条（対象商品の購入及び発送）

  1. 乙は、自己の責任と負担においてApple Storeにて対象商品を購入するものとします。
  2. 乙は、対象商品の配送先を甲が案内する指定倉庫の住所に指定し、購入時の登録メールアドレスを、あらかじめ甲と連携したGmailアドレスと一致させるものとします。
  3. 対象商品が指定倉庫に到達した後は、乙は当該商品の返送、キャンセル又は撤回を求めることができません。

第7条（買取契約の成立）

  1. 甲は、指定倉庫に到達した対象商品を検品の上、買取価格を査定し、LINE上で乙に対して買取金額（以下「確定金額」）を通知します。
  2. 乙が当該通知に対し所定の方法（「買取金額承諾」操作等）により承諾したときに買取契約が成立し、対象商品の所有権は乙から甲へ移転します。
  3. 買取契約の成立後、乙は当該対象商品について何らの権利も有しません。

第8条（買取代金の支払）

  1. 甲は、買取業者からの入金確認後、確定金額から第11条の手数料等を控除した金額を、乙が登録した銀行口座へ振込送金します。
  2. 送金に要する日数は金融機関の処理状況により異なり、甲はこれについて責任を負いません。
  3. 乙は、送金に先立ち、追跡番号の報告その他発送状況の報告を行う必要はありません。

第9条（キャンセルの禁止）

乙は、対象商品が指定倉庫に到達した後、当該商品に係る取引について一切のキャンセル、返品又は返金を求めることができません。ただし第10条の早期返金の申出はこの限りではありません。

第10条（早期返金の申出）

  1. 乙は、買取契約成立後、送金完了前に限り、甲に対し買取代金の早期支払（以下「早期返金」）を申し出ることができます。
  2. 早期返金の申出があったときは、対象商品1台につき金1万円（消費税別）の手数料を確定金額から追加で控除します。

第11条（手数料）

甲は、買取契約に基づき生じる利益（確定金額から対象商品の購入代金相当額を控除した額）に対し、甲が別途定める料率又は定額（機種により異なる場合があります）による手数料を控除します。料率及び金額は、甲が事前の予告なく変更することがあります。

第12条（古物営業法に基づく届出義務）

乙は、2回目以降の買取契約を締結しようとする場合、古物営業法に基づき自ら必要な許可を取得し、その許可証番号を甲に届け出るものとします。届出がない場合であっても買取契約自体の成立は妨げませんが、届出完了までの間、甲は買取代金の送金を留保することができます。
